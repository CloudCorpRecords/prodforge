# taskboard

A worked SaaS example: generated by `prodforge init saas-web taskboard`, then extended with a real feature — an in-memory task board API on top of the generated health endpoint.

Stack: `saas-web` (generated by `prodforge init saas-web taskboard`).

## What it shows, end to end

1. **Generate:** `prodforge init saas-web taskboard` gives you package.json, tsconfig, src, and a node:test suite — no framework, node builtins only.
2. **Extend:** `src/index.ts` adds a `TaskStore` (list/create with validation) beside the generated health endpoint: `GET /health`, `GET /tasks`, `POST /tasks`.
3. **Test:** `npm test` runs the suite — health, task create/list, 400 on an empty title, 404 on unknown routes.
4. **Run:** `npm start` serves on `PORT` (default 3000). Try it:
   ```sh
   curl localhost:3000/health
   curl -X POST localhost:3000/tasks -H 'content-type: application/json' -d '{"title":"Ship it"}'
   curl localhost:3000/tasks
   ```
5. **Ship:** from the repo root, `prodforge checklist` and `prodforge ship` run the production gate before you tag — GO means ship it.

## Develop

```sh
npm install
npm test
npm run build
npm start
```
